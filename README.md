# AI Code Reviewer

An AI-powered web application that reviews source code and provides feedback, suggestions, and potential improvements.

## 📌 About the Project

AI Code Reviewer is a web-based tool designed to help developers analyze their code using AI.

Users can enter their source code into the application and request an AI-powered review. The application processes the code and presents the review in an easy-to-understand format.

This project was developed as part of my Artificial Intelligence Engineer internship.

## ✨ Features

- 🧠 AI-powered code review
- 💻 Simple and responsive web interface
- 📝 Code input and analysis
- 🔍 Identifies potential issues and improvement areas
- 💡 Provides suggestions for improving code
- 📊 Displays review results in an easy-to-understand format

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- AI API
- GitHub
